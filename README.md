```
現状の問題あるある場面「こんな感じのものが欲しい」が伝わらない発注者とエンジニアの断絶仕様書を書くスキルがない非エンジニアのアイデアが形にならない要件定義に時間がかかりすぎる何度も「違う、そうじゃない」のループイメージはあるのに言語化できない頭の中のビジョンが共有できない
```

💡 機能イメージ
Phase 1: 抽象イメージの収集

```
ユーザー: 「なんかこう、チームの雰囲気が分かるようなやつ」

AI: いくつか質問させてください。
    - 誰が使いますか？（マネージャー？メンバー全員？）
    - どんな時に見たいですか？（毎日？問題が起きた時？）
    - 「雰囲気が分かる」とは具体的にどんな状態ですか？
    - 似ているサービスや、参考イメージはありますか？
```

Phase 2: 対話による具体化

```
AI: こういうことですか？
    「Slackの発言トーンを分析して、チームの
    ポジティブ/ネガティブ度を毎週スコア表示する」

ユーザー: うーん、スコアというより、もっと直感的に...

AI: では「天気」で表現するのはどうですか？
    ☀️晴れ / ⛅曇り / 🌧️雨 のように。

ユーザー: それそれ！
```

Phase 3: 仕様書自動生成

```
【自動生成される仕様書】

■ プロダクト名（仮）: Team Weather
■ 概要: チームのコミュニケーション状態を天気で可視化

■ 機能要件:
1. Slack連携でメッセージを取得
2. 感情分析APIでトーンを判定
3. 週次で「天気予報」形式のダッシュボード表示
4. 悪天候が続いたらマネージャーにアラート

■ 非機能要件:
- プライバシー: 個人は特定しない、チーム単位で集計
- 更新頻度: 週1回（月曜朝）

■ MVP（最小構成）:
- Slack連携 + 感情分析 + 天気表示のみ

■ 技術構成案:
- Slack API / Google Cloud Natural Language / React
```
